## Модуль 11 (layout) — прогресс (2026-07-21 — 2026-07-23)
Работали в lib/main.dart с Row + Container + Center + Text + Padding/SizedBox.
Закрытые темы (понял и подтвердил на практике, не просто услышал):
- `Center` не растягивает ребёнка — даёт ему занять собственный (intrinsic) размер и просто центрирует блок.
  Из-за этого `textAlign` не даёт видимой разницы, если у Text нет свободного места внутри себя.
- Правило layout: constraints идут от родителя к ребёнку (сверху вниз), размер ребёнок выбирает сам, но
  строго в этих границах — сверху вылезти не может. Проверено на практике: `Container(width: 100)` +
  `SizedBox(width: 150)` внутри — сжимается до 100; без ограничения ширины у `Container` — вылезает.
- `Padding` без `child` как "распорка" — работает, но не по назначению. Правильный виджет для чистого
  отступа/расстояния — `SizedBox(width: ...)` без child. Заменил на практике, визуально не изменилось.

Оставшиеся темы модуля 11 (не начаты): Column, Expanded, ListView, GridView, SnackBar, Dialog, BottomSheet.

## Новый формат работы над UI (с 2026-07-28)
Для экрана "Наша квартира" (home_page.dart и виджеты в presentation/widgets/) действует отдельный поток,
параллельный основному курсу Dart (там всё ещё "пишет пользователь, ассистент направляет"):
1. Пользователь присылает референс экрана (скриншот/описание).
2. Ассистент пишет код экрана целиком.
3. Пользователь читает код и спрашивает про непонятные виджеты.
4. По каждому виджету: сначала прямая теория (без вопросов), затем 3 практических задания
   (лёгкое/среднее/сложное) на использование этого виджета.
Практика делается в lib/sandbox/ — отдельные файлы, не трогающие рабочие экраны приложения; каждый
sandbox-файл содержит свой `main()`, запускается отдельно (`flutter run -t lib/sandbox/<file>.dart`).
